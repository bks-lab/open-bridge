BKS open-bridge is a framework, not a product with one fixed workflow. Below are eight concrete jobs teams run on it, then five moments from a day with a long-running instance.

01 FlagshipFlaggschiff

Org-aware without forking Org-bewusst ohne Fork

ProblemProblem Every teammate needs your org's customizations (skills, configs, accounts), but forking a tailored bridge per person is unmaintainable. Jede:r im Team braucht die Anpassungen deiner Organisation (Skills, Configs, Accounts), aber pro Person eine angepasste Bridge zu forken ist nicht wartbar.

What the bridge doesWas die Bridge tut /overlay add <git-url> subscribes a vanilla bridge to a private org-config repo and materializes its files across your tree as tracked copies, recorded in a manifest and a lockfile. It is the downstream inverse of /bridge-promote. CORE files are never overridable; managed files stay public-fork-safe; and your own edits always win on conflict. One URL gives a teammate a full org bridge: no fork, no per-person drift. /overlay add <git-url> abonniert für eine unveränderte Bridge ein privates Org-Config-Repo und materialisiert dessen Dateien über deinen Baum verteilt als getrackte Kopien, festgehalten in einem Manifest und einem Lockfile. Es ist die Downstream-Umkehrung von /bridge-promote. CORE-Dateien sind nie überschreibbar; verwaltete Dateien bleiben public-fork-sicher; und bei Konflikt gewinnen stets deine eigenen Edits. Eine URL gibt einem Teammitglied eine vollständige Org-Bridge: kein Fork, kein Drift pro Person.

02

Client status updates with sender discipline Kunden-Status-Updates mit Absender-Disziplin

ProblemProblem Recurring status emails to clients must come from you, with correct attribution, and must never address the recipient as "you". Wiederkehrende Status-Mails an Kunden müssen von dir kommen, mit korrektem Absender, und dürfen die Empfänger nie mit „Du" ansprechen.

What the bridge doesWas die Bridge tut Turn a task or board item into a styled email routed to the right recipient group, optionally scheduled for later. The sender is always you; recipients are kept in the third person by construction, so attribution never slips. Verwandle einen Task oder ein Board-Item in eine gestylte E-Mail, geroutet an die richtige Empfängergruppe, optional für später geplant. Absender bist immer du; Empfänger bleiben konstruktionsbedingt in der dritten Person. Der Absender verrutscht nie.

Meeting → protocol → tasks Meeting → Protokoll → Tasks

ProblemProblem Meeting decisions evaporate the moment the call ends. Meeting-Entscheidungen verdampfen, sobald das Gespräch endet.

What the bridge doesWas die Bridge tut A debrief step takes your meeting notes, classifies the meeting, extracts insights across categories, and proposes board-mapped tasks you approve, so a conversation becomes tracked work instead of a fading memory. Ein Debrief-Schritt nimmt deine Meeting-Notizen, klassifiziert das Meeting, extrahiert Erkenntnisse über Kategorien hinweg und schlägt board-zugeordnete Tasks vor, die du freigibst. Aus einem Gespräch wird getrackte Arbeit statt verblassender Erinnerung.

04

Document intake & filing Dokumenten-Intake & Ablage

ProblemProblem Inboxes and mail attachments pile up unsorted until nothing can be found. Postfächer und Mail-Anhänge stapeln sich unsortiert, bis nichts mehr auffindbar ist.

What the bridge doesWas die Bridge tut The doc-system scans your sources (filesystem inboxes and flagged mail), categorizes each document, and files it using routing rules plus per-persona destinations, for example a PARA tree. Renamed, tagged, filed, and audited. Das Doc-System scannt deine Quellen (Dateisystem-Inboxen und geflaggte Mails), kategorisiert jedes Dokument und legt es per Routing-Regeln plus Persona-Zielpfaden ab, etwa einem PARA-Baum. Umbenannt, getaggt, abgelegt und auditiert.

05

Multi-instance data isolation Multi-Instanz-Datentrennung

ProblemProblem Different orgs' or clients' data must never share a git history. Daten verschiedener Organisationen oder Kunden dürfen nie eine Git-Historie teilen.

What the bridge doesWas die Bridge tut Run a separate bridge instance per org: each its own clone with its own user branch, some pushed to a remote, some kept local-only. A registry indexes them all, so you stay aware of every instance without ever cross-contaminating their data. Betreibe eine eigene Bridge-Instanz pro Organisation: jede ein eigener Clone mit eigenem User-Branch, manche zu einem Remote gepusht, manche nur lokal. Eine Registry indiziert sie alle, sodass du jede Instanz im Blick hast, ohne dass sich ihre Daten je vermischen.

06

Knowledge that grows itself Wissen, das sich selbst aufbaut

ProblemProblem Lessons learned in one session are forgotten by the next. In einer Session Gelerntes ist bis zur nächsten vergessen.

What the bridge doesWas die Bridge tut A file-based memory keeps durable facts as plain text the agent reads back later. A learning loop closes the gap: postmortems and audits emit improvement proposals you review, and a curator consolidates recurring patterns, so the system compounds instead of forgetting. Ein dateibasiertes Gedächtnis hält dauerhafte Fakten als Klartext, den der Agent später wieder liest. Eine Lernschleife schließt die Lücke: Postmortems und Audits erzeugen Verbesserungsvorschläge, die du prüfst, und ein Kurator konsolidiert wiederkehrende Muster. Das System wächst, statt zu vergessen.

07

Cross-tool skills, private by default Tool-übergreifende Skills, privat per Default

ProblemProblem Tooling built for one agent CLI is stuck there, and contributing improvements upstream risks dragging private org content along. Tooling, das für ein einzelnes Agent-CLI gebaut ist, bleibt dort hängen, und Verbesserungen upstream beizutragen riskiert, private Org-Inhalte mitzuschleppen.

What the bridge doesWas die Bridge tut Agent Skills follow the open SKILL.md standard, discoverable by Claude Code, Codex and Copilot CLI through one shared tree, symlinked into .claude/, .agents/ and .github/. A three-tier promote/contribute flow routes every change by its scope, so private content stays local while generic CORE content flows upstream, decided by structure, not by a tag you can forget. Agent-Skills folgen dem offenen SKILL.md-Standard, auffindbar für Claude Code, Codex und Copilot CLI über einen gemeinsamen Baum, verlinkt nach .claude/, .agents/ und .github/. Ein dreistufiger Promote/Contribute-Fluss routet jede Änderung nach ihrem Scope, sodass private Inhalte lokal bleiben und generische CORE-Inhalte upstream fließen, entschieden durch Struktur, nicht durch ein Tag, das man vergessen kann.

08

Multi-repo client/engagement work Multi-Repo-Kunden-/Engagement-Arbeit

ProblemProblem A client or engagement spans several repos plus an org config overlay. Nothing names that they belong together, or tracks whether the clones have drifted. Ein Kunde oder Engagement erstreckt sich über mehrere Repos plus ein Org-Config-Overlay. Nichts benennt, dass sie zusammengehören, oder verfolgt, ob die Clones auseinandergelaufen sind.

What the bridge doesWas die Bridge tut A workspace names the binding: the member repos plus the org config overlay it draws on. Clones live in the gitignored .bridge/ tree, public-fork-safe by construction, and status shows at a glance whether any member has drifted from its pinned ref. Ein Workspace benennt die Bindung: die Mitgliedsrepos plus das Org-Config-Overlay, auf das er sich stützt. Clones liegen im gitignorten .bridge/-Baum, konstruktionsbedingt sicher für öffentliche Forks, und status zeigt auf einen Blick, ob ein Mitglied vom gepinnten Ref abgewichen ist.

09 A day with itEin Tag damit

Morning triage Morgen-Triage

ProblemProblem A morning starts with a dozen dashboards, inboxes and boards to check before you know what actually needs you. Ein Morgen beginnt mit einem Dutzend Dashboards, Postfächern und Boards, bevor klar ist, was dich wirklich braucht.

What the bridge doesWas die Bridge tut “good morning” returns one list: a client’s overnight error report has two new failure clusters, a backup target is three days stale, a tax document is due Friday, two applications have had no reply for over ten days. Nothing else is shown, because the rest is green. „Guten Morgen“ liefert eine Liste: der nächtliche Fehlerbericht eines Kunden hat zwei neue Fehlercluster, ein Backup-Ziel ist drei Tage alt, ein Steuerdokument ist Freitag fällig, zwei Bewerbungen sind seit über zehn Tagen unbeantwortet. Mehr wird nicht gezeigt, weil der Rest grün ist.

After a call Nach einem Gespräch

ProblemProblem The call ended an hour ago, and the protocol, the follow-up tasks and the recap mail are still in your head. Das Gespräch ist seit einer Stunde vorbei, und Protokoll, Folgeaufgaben und Zusammenfassung stecken noch im Kopf.

What the bridge doesWas die Bridge tut The recording becomes a transcript, the transcript a protocol in the team wiki, three proposed board items waiting for your approval, and a recap mail as a draft. The agent does not send it; you press send. Aus der Aufnahme wird ein Transkript, daraus ein Protokoll im Team-Wiki, drei vorgeschlagene Board-Einträge, die auf deine Freigabe warten, und eine Zusammenfassungs-Mail als Entwurf. Der Agent sendet sie nicht; du drückst auf Senden.

An incident without context loss Ein Vorfall ohne Kontextverlust

ProblemProblem A log search floods the session with thousands of lines, and by tomorrow nobody remembers what was found. Eine Log-Suche flutet die Session mit Tausenden Zeilen, und morgen weiß niemand mehr, was gefunden wurde.

What the bridge doesWas die Bridge tut “What happened to invoice X?” A sub-agent searches the logs and returns a short delta table instead of a log dump. The finding is filed into the inbox and closes itself when the live source says it is fixed. A log row keeps the history, so tomorrow’s session resumes mid-thought. „Was ist mit Rechnung X passiert?“ Ein Sub-Agent durchsucht die Logs und liefert eine kurze Delta-Tabelle statt eines Log-Dumps. Der Befund wird im Posteingang abgelegt und schließt sich selbst, sobald die Live-Quelle „behoben“ sagt. Eine Log-Zeile hält die Historie fest, sodass die Session morgen mitten im Gedanken weitermacht.

12 A day with itEin Tag damit

Wearing another hat Ein anderer Hut

ProblemProblem You work for a company, for freelance clients and for yourself, and each needs a different signature, filing place and board. Du arbeitest für eine Firma, für Freelance-Kunden und für dich selbst, und jede Rolle braucht eine andere Signatur, Ablage und ein anderes Board.

What the bridge doesWas die Bridge tut Switching to a freelance client swaps the signature, the filing path and the board. A private task never syncs to any tracker, because its STATUS.md says bridge_only: true. Der Wechsel zu einem Freelance-Kunden tauscht Signatur, Ablagepfad und Board. Eine private Aufgabe synchronisiert nie mit einem Tracker, weil in ihrer STATUS.md bridge_only: true steht.

13 A day with itEin Tag damit

The quiet server Der ruhige Server

ProblemProblem Dozens of scheduled jobs run on a small home server, and a config file that says “running” proves nothing. Dutzende geplante Jobs laufen auf einem kleinen Heimserver, und eine Config-Datei, in der „running“ steht, beweist nichts.

What the bridge doesWas die Bridge tut Every job is declared in one file. The agent never trusts a status field; it asks the service manager, and only a broken or stale job becomes a morning line with a fix hint. Jeder Job ist in einer Datei deklariert. Der Agent vertraut nie einem Statusfeld; er fragt den Service-Manager, und nur ein kaputter oder veralteter Job wird zu einer Morgenzeile mit Reparaturhinweis.
